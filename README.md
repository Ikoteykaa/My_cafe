# ☕ My Cafe Bill

> A robust console application written in C# for managing cafe bills efficiently.

## 📖 Description

**My Cafe Bill** is a console application that allows the user to easily create and manage a cafe bill. With this program, you can add and remove items, calculate the total cost, manage tips, and save or load bills from a file. It is designed with user experience in mind, ensuring stability and ease of use.

## ✨ Main Features

*   **➕ Add & Remove Items:** Easily modify the current bill.
*   **💸 Add Tip:** Support for both percentage-based and fixed amount tips.
*   **🧾 Display Bill:** View the complete bill with calculated totals.
*   **🧹 Clear Bill:** Reset the current session instantly.
*   **💾 Save & Load:** Persist your bills to a file and retrieve them later.
*   **🛡️ Input Validation:** Ensures only correct and valid data is processed.
*   **⚙️ Error Handling:** The program is stable and does not crash on incorrect user input.
